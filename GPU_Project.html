Parallel Sorting Optimization Using CUDA & NSight Compute

Project of CS8803 GPU Hardware & Software
(Jan 2025 — Feb 2025)

  • Implemented Bitonic Sort using CUDA, optimizing shared memory kernels and leveraging pinned memory for efficient data transfer.
  • Analyzed performance bottlenecks using NVIDIA Nsight Compute to optimize GPU occupancy and memory throughput to achieve a 180× speedup over std::sort on CPU.
